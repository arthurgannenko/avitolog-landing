# ИИ-решения — учебная адаптация AutomateX

Главная страница русскоязычного сайта услуг: голосовые ИИ-агенты и диалоговые ИИ-ассистенты. HTML, CSS и обычный JavaScript. Без зависимостей, сборки, API, оплаты, базы данных, аналитики и внешних форм.

## Текущий этап

Реализована **только главная страница** по двум предоставленным скриншотам AutomateX: полная компьютерная страница и крупный первый экран. Доступ к живому референсу из облачной среды не получен; его раскрытые меню, интерактивные состояния и мобильная версия не были просмотрены. Они адаптированы самостоятельно в характере предоставленного макета.

Остальные страницы будут добавлены после получения их скриншотов:

- `services/voice-agents.html` — голосовые ИИ-агенты;
- `services/conversational.html` — диалоговые ИИ-ассистенты;
- `use-cases.html` — сценарии применения.

Сейчас пункты услуг ведут к соответствующим карточкам главной, а «Сценарии применения» — к блоку задач бизнеса. Несуществующих страниц и пустых ссылок нет. «О компании», «Тарифы» и «Контакты» ведут к блокам главной. Все кнопки консультации и плавающая кнопка поддержки ведут к единому блоку контактов.

## Скачать и посмотреть

1. Откройте ветку `feat/ai-solutions` в GitHub.
2. Нажмите **Code → Download ZIP** и распакуйте архив.
3. Откройте `index.html` в браузере. Все пути относительные, шрифты и графика локальные; работа сайта не требует интернета. Этот способ предусмотрен кодом, но в облачной среде не проверен: Chromium запрещает `file://` политикой администратора.

**Проверенный способ — локальный HTTP-сервер.** Если установлен Python 3, откройте терминал в распакованной папке проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в браузере на своём компьютере. Для остановки нажмите `Ctrl+C` в терминале. Устанавливать пакеты npm не нужно.

В облачной среде рабочая папка: `/workspace/avitolog-landing`. Сервер можно запустить из неё командой `python3 -m http.server 8000 --bind 0.0.0.0`. Облачный локальный адрес не является публичной ссылкой. На внешнем хостинге сайт не опубликован.

Основные блоки: первый экран с орбитальной графикой, демонстрационные показатели, платформы для интеграций, задачи бизнеса, две услуги, четыре этапа работы, три тарифа, описание проекта, контакты и подвал. Пояснения к тарифам раскрываются без JavaScript через `<details>`.

## Чем эта версия отличается от референса

- Название и содержание адаптированы под «ИИ-решения». Тексты на русском; названия сторонних платформ не переведены. Мелкие тексты восстановлены по смыслу, а не как дословная копия неразборчивого текста скриншота.
- В блоке услуг две равные карточки вместо исходной сетки из шести. Внутри добавлены декоративные примеры звонка и чата; это не настоящие агенты.
- В меню нет блога и Resource Center; пока нет трёх внутренних страниц. Ссылки ведут на блоки главной.
- Шрифт заменён на локальный Manrope с кириллицей. Переносы строк и высота блоков адаптированы под русский текст.
- Мобильная версия, раскрытые меню и светлая тема разработаны самостоятельно: для них скриншотов оригинала пока нет. Из анимаций — только мягкое свечение орбиты и состояния наведения; учтён `prefers-reduced-motion`.
- Показатели отмечены как учебные. Цены из референса сохранены без пересчёта: $3,000 + от $500/мес.; $5,000 + от $1,000/мес.; индивидуальный расчёт. Это учебные данные, не оферта.
- Чужие контакты, сведения об основателях, отзывы и результаты клиентов не использованы. Блок компании честно описывает учебный проект. Контакты ещё не добавлены, отправка заявки не имитируется.
- Убраны внешние формы, чат, юридические ссылки и cookie-интерфейс. Кнопка с гарнитурой только прокручивает к контактам. Добавлены компактные раскрывающиеся пояснения к учебным тарифам.

## Проверки

На **390 и 1440 px** в Chromium через статический сервер проверены:

- визуальная композиция; сняты и просмотрены скриншоты;
- раскрывающиеся меню: клик, клавиатура, Escape, а на компьютере — наведение;
- мобильное меню, переход по его ссылке и закрытие при расширении окна;
- якоря, все цели ссылок и кнопки консультации;
- раскрытие пояснений к тарифам и переключение темы;
- загрузка локальных изображений и шрифтов;
- отсутствие горизонтальной прокрутки, ошибок JavaScript и HTTP;
- отсутствие внешних сетевых запросов страницы.

Дополнительно проверено отсутствие горизонтальной прокрутки и обрезанных заголовков/кнопок на 320, 600, 768, 900, 1024 и 1920 px. `node --check script.js` и `git diff --check` проходят.

Прямое открытие через `file://` не проверено: облачный Chromium возвращает `ERR_BLOCKED_BY_ADMINISTRATOR`. Сравнение с мобильной версией оригинала и проверки трёх будущих страниц не выполнялись.
