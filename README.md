# Лендинг Артура — авитолог и ИИ-ассистенты

Учебный одностраничный сайт на HTML, CSS и обычном JavaScript. Без зависимостей, сборщика, базы данных, оплаты и подключения ИИ.

## Как посмотреть

Самый простой способ: скачайте файлы проекта и откройте `index.html` в браузере. Стили, изображения и меню работают без сервера.

Для просмотра через локальный сервер, если установлен Python 3:

```sh
cd /workspace/avitolog-landing
python3 -m http.server 8000 --bind 0.0.0.0
```

На своём компьютере замените путь на путь к скачанной папке проекта. Откройте в браузере адрес `http://localhost:8000`. Остановить сервер: `Ctrl+C`. В облачной среде локальный адрес доступен только внутри среды; публичной ссылки предпросмотра здесь нет. Для просмотра на своём компьютере скачайте папку проекта.

## Файлы

- `index.html` — содержание и восемь основных разделов.
- `styles.css` — оформление и адаптивная вёрстка.
- `script.js` — мобильное меню и год в подвале.
- `assets/` — SVG-заглушка портрета и иконка сайта.

## Что заменить перед использованием

1. Добавить настоящий портрет вместо `assets/portrait-placeholder.svg`, обновить путь и описание изображения в HTML.
2. Указать контакты в блоке `#contacts`. Сейчас все кнопки связи ведут туда, данные не собираются.
3. Согласовать услуги и цены. Все текущие цены явно обозначены как демонстрационные.
4. Добавить реальные кейсы с разрешения клиентов. Пока показано «Раздел готовится».

Референс `https://danilova-target.ru/` при разработке оказался недоступен из облачной среды (ошибка туннеля / HTTP 403). Дизайн референса не был просмотрен; эта версия создана по перечню блоков из задания и не заявляет визуального совпадения с ним.

## Проверки первой версии

В Chromium через локальный HTTP-сервер проверены ширины 390 и 1440 px: все якорные ссылки, кнопка связи, загрузка ресурсов, отсутствие горизонтальной прокрутки и ошибок JavaScript. На мобильной ширине проверены открытие меню, закрытие по ссылке и Escape, а также переход к широкой версии. Сняты и просмотрены скриншоты. `node --check script.js` и `git diff --check` проходят.

Открытие через `file://` в облачном Chromium заблокировано политикой браузера, поэтому этот способ здесь не проверен; проверенный вариант — HTTP-сервер выше.
